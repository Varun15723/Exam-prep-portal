# Exam Prep Portal

An AI-powered exam preparation platform built with Flask, SQLAlchemy, and Google Gemini. Features include quizzes, analytics dashboards, AI study planners, and a chatbot.

## Tech Stack

- **Backend:** Flask, SQLAlchemy, Flask-JWT-Extended, Flask-Bcrypt
- **AI:** Google Gemini 1.5 Flash
- **Database:** SQLite (local) / PostgreSQL (production)
- **Server:** Gunicorn

## Local Development

```bash
# Clone the repo
git clone <your-repo-url>
cd exam-prep-portal

# Create a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux

# Install dependencies
pip install -r requirements.txt

# Run the dev server
python run.py
```

The app will be available at `http://127.0.0.1:5000`.

## Deploy to Render

1. Push this repo to GitHub.
2. Go to [Render Dashboard](https://dashboard.render.com) → **New** → **Blueprint**.
3. Connect your GitHub repo — Render will detect `render.yaml` and provision:
   - A **free PostgreSQL** database (`exam-prep-db`)
   - A **free web service** (`exam-prep-portal`)
4. After deploy, set the **GEMINI_API_KEY** environment variable in the Render dashboard under the web service → Environment.

> **Note:** `SECRET_KEY` and `JWT_SECRET_KEY` are auto-generated by Render. `DATABASE_URL` is injected automatically from the managed database.

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `DATABASE_URL` | Auto | PostgreSQL connection string (injected by Render) |
| `SECRET_KEY` | Auto | Flask secret key (auto-generated on Render) |
| `JWT_SECRET_KEY` | Auto | JWT signing key (auto-generated on Render) |
| `GEMINI_API_KEY` | **Yes** | Google Gemini API key |
